# IPoUGRS — IP over Unanswered GSM Ring Signals

`draft-papadopoulos-ipougrs-00` · IETF Independent Submission ·
Informational · Target: January 2027

> "The best April Fools protocol since IP over Avian Carriers —
> except the hardware actually works."

IPoUGRS encodes IP datagrams as sequences of GSM ring signals.
A ring present encodes binary 1. An absent ring encodes binary 0.
Eight parallel phone calls encode one byte per ring cycle.
The called party never answers.

## Specification

| Property | Value |
|---|---|
| Encoding | Ring=1, Silence=0 (unipolar NRZ) |
| Minimum implementation | 2 phones (1 bps) |
| Reference implementation | 32 phones, 16 TX + 16 RX |
| Throughput (reference) | ~1,6 bps per channel |
| Aggregate (16 channels) | ~25,6 bps theoretical |
| Duplex | Full duplex (separate TX/RX banks) |
| Latency | 640ms per bit (VoLTE ring cycle) |
| Cost | EUR 0 (unanswered calls are free on most carriers) |

## Why This Exists

RFC 1149 (IP over Avian Carriers, 1990) proved that any sufficiently
absurd physical medium can carry IP datagrams given sufficient
creativity. RFC 2549 added QoS. RFC 6214 added IPv6.

IPoUGRS extends this tradition to the GSM signalling plane,
demonstrating that the ring signal — a side effect of call setup,
never intended as a data channel — can carry arbitrary IP traffic
at a throughput comparable to early acoustic modems, with the
additional property that the communication is completely invisible
to the carrier's data monitoring infrastructure.

The draft was submitted to the IETF Independent Submission Editor
on March 11, 2026. The ISE responded the same day.

## Technical Basis

The GSM ring signal is generated by the network when a mobile
subscriber is being called, before the called party answers or
rejects. This signal is observable by the called device without
establishing a voice channel. By timing the presence and absence
of ring signals, binary data can be conveyed without the call
ever being answered.

On VoLTE networks, ring cycles are approximately 640ms (2s ring,
4s silence = 3s cycle). Shorter cycles are achievable on some
carriers by calling and immediately timing out.

## IPoUGRS as a HeMB Bearer

IPoUGRS is formally registered as a bearer type in the HeMB
(Heterogeneous Media Bonding) protocol
([draft-papadopoulos-hemb-00](https://github.com/papadopouloskyriakos/hemb)):

- MTU: 1 byte per slot
- Cost: EUR 0
- Loss rate: ~30%
- Latency: 8.000ms per byte
- Role: last-resort bearer when all data channels fail

## Hardware

The reference implementation uses 34x SIM800L GSM modules:
- 16 modules per node (TX bank + RX bank)
- CP2102 USB-UART adapters (one per module)
- LM2596 buck converters at 4,0V
- 36x Lebara prepaid SIM cards (unanswered calls, voice-only)

Total PoC cost: EUR 351

See [impl/hardware/README.md](impl/hardware/README.md) for full
wiring and power supply details.
