# ISE Submission — March 11, 2026

**To:** rfc-ise@rfc-editor.org
**Subject:** Independent Submission — draft-papadopoulos-ipougrs-00
**Date:** March 11, 2026

Submitted draft-papadopoulos-ipougrs-00 (IP over Unanswered GSM Ring
Signals) for consideration as an Informational RFC on the Independent
Submission Stream.

The draft specifies a method for encoding IP datagrams as sequences of
GSM ring signals, in the tradition of RFC 1149 (IP over Avian Carriers).
A reference hardware implementation using 34 SIM800L GSM modules is
under construction.

Requested track: Informational.
Target publication: April 1, 2027 (following the tradition).
